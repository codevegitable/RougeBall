# 突破地牢

基于 Canvas 的弹球闯关小游戏：移动鼠标控制挡板，点击发射小球，击碎所有方块过关。

## 游戏系统

- **奖励体系（34 种效果）**
  - 三种稀有度：普通 / 罕见 / 稀有，稀有度越高效果越强
  - 三类效果：加成（数值提升）/ 技能（主动释放，最多装备 2 个，数字键 1/2 释放）/ 能力（被动与局外收益，如奖励选卡 +1、稀有概率提升）
  - 开局从 3 张随机稀有度的奖励中任选一张
- **关卡难度递增**：方块血量提高、不可击碎方块（障碍物，清光其他方块即可过关）、左右移动的方块、会向挡板射击的方块；方块尺寸随层数从 96×30 缩小至 48×17；每关数量 10~50 随机布局
- **Boss 战**：第 15 / 30 / 45 / 50 关是东方风格弹幕 Boss；Boss 关球落地不扣血，被弹幕击中才扣血；击败 Boss 必掉 Boss 专属奖励（泰坦之臂/灭世冲击/时间编织者/弹幕领主/王之财宝/神速之星，独有且强力），选完后还需选择一项惩罚。Boss 拥有多种技能：扇形/环形/分裂/追踪/波浪/螺旋弹幕，以及身体冲撞和卫星守卫
- **事件房**：过关后有概率遭遇事件（14 种），包括商人/赌局/生命泉/暗影祭坛/虚空裂缝/圣光/黑市/篝火/附魔工坊/时光裂缝/许愿井/遗迹图书馆/限时挑战/封印之间；可选跳过，选完先显示结果再离开
- **新手引导**：每次新特性首次出现时弹出半透明引导面板，游戏暂停等待点击。覆盖：开局选卡、基本操作、技能、不可击碎方块、移动方块、重甲砖、Boss 战（每类 Boss 单独介绍其技能与弹幕）、事件房、诅咒、限时挑战。已看过的引导跨存档永久记录
- **诅咒系统**：击败 Boss 后强制选择一项惩罚（20 种中文诅咒），强度随层数递增且永久生效；重诅咒（5 种）仅出现在事件惩罚中，诅咒随存档保存
- **分数解锁**：累积分数达 6000/20000/40000 解锁 3 套皮肤（翡翠/绯红/金辉）和 6 个独家奖励
- **图鉴系统**：菜单或 ESC 暂停可进入图鉴，查看全部奖励/诅咒/事件数据
- **暂停与存档**：ESC 暂停（继续/重开/保存退出/图鉴）；进度自动保存到 localStorage，主菜单可继续上次冒险
- **打击感与音效**：震屏、顿帧、冲击波、漂浮文字，受击红闪遮罩，Web Audio 程序化音效；按 M 键开关音效
- **彩蛋**：主菜单/游戏中输入 ↑↑↓↓←→←→BA 激活魂斗罗秘籍，获得 30 条命+全奖励+Boss Rush 模式

## 开发

```bash
npm install
npm run dev      # 启动开发服务器（默认 http://localhost:8080，自动打开浏览器）
npm run build    # 构建到 dist/，直接打开 dist/index.html 即可游玩
```

## 配置

`src/js/config.js`：音效开关与音量、震屏、顿帧、事件房概率。

## 目录结构

```
src/
├── index.html          # 页面模板
├── css/style.css       # 样式
└── js/
    ├── data/           # ═══ 纯数据（与程序分离，可直接编辑） ═══
    │   ├── rewards.js  #   奖励数据（40+ 种：加成/技能/能力/Boss专属/皮肤技能）
    │   ├── curses.js   #   诅咒数据（20 常规 + 5 重诅咒）
    │   ├── events.js   #   事件房数据（14 种，含选项与行为描述）
    │   ├── bosses.js   #   Boss 数据（每层 2 候选，含弹幕模式）
    │   ├── skins.js    #   皮肤与解锁数据（3 皮肤 + 开场技能）
    │   └── levels.js   #   关卡数据（方块尺寸表/血量表）
    ├── index.js        # 入口：初始化、输入处理、游戏循环
    ├── config.js       # 打击感、音效与进程配置
    ├── constants.js    # 常量：尺寸、颜色、状态、稀有度、进度
    ├── state.js        # 全局共享的游戏状态与记分/扣血
    ├── canvas.js       # Canvas 初始化与窗口缩放
    ├── utils.js        # 通用工具函数
    ├── stars.js        # 星空背景
    ├── particles.js    # 粒子特效
    ├── levels.js       # 关卡生成逻辑（读取 data/levels.js）
    ├── rewards.js      # 奖励逻辑：选卡、属性重算、技能释放（读取 data/rewards.js）
    ├── events.js       # 事件逻辑：行为解释器（读取 data/events.js）
    ├── curses.js       # 诅咒逻辑：效果绑定（读取 data/curses.js）
    ├── boss.js         # Boss 战：弹幕、命中、绘制（读取 data/bosses.js）
    ├── physics.js      # 挡板/球/方块/敌弹物理与连锁效果
    ├── game.js         # 游戏流程：重置、关卡、奖励、诅咒、事件、主循环 update
    ├── render.js       # 游戏画面绘制（挡板/球/方块/Boss 等）
    ├── ui.js           # HUD 与各界面绘制、按钮命中检测、图鉴、设置
    ├── unlock.js       # 分数解锁系统（皮肤 + 奖励池）
    ├── settings.js     # 持久化游戏设置
    ├── fx.js           # 打击感特效：震屏/顿帧/圆环/红闪/漂浮文字
    └── sound.js        # Web Audio 程序化音效
```
